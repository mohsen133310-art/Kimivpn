# KimiVPN

### امن، ساده و سریع

**کلاینت VPN اندرویدی با رابط اختصاصی سفید و بنفش**

</div>

## وضعیت پروژه

KimiVPN یک نسخهٔ تغییریافته و برندشده بر پایهٔ پروژهٔ متن‌باز [GRoute](https://github.com/SuOracle/GRoute) است. موتور اتصال Xray و اجزای اصلی شبکه از پروژهٔ بالادستی حفظ شده‌اند؛ رابط و هویت بصری KimiVPN به‌تدریج اختصاصی می‌شوند.

## قابلیت‌های پایه

- پشتیبانی از لینک‌های VLESS و VMess
- پشتیبانی از HTTP Proxy
- ورود کانفیگ از کلیپ‌بورد، فایل و QR (مطابق امکانات نسخهٔ پایه)
- اتصال از طریق Android VPN Service
- رابط فارسی و راست‌چین
- تم سفید و بنفش KimiVPN

## دریافت نسخهٔ آزمایشی

فایل‌های APK آزمایشی پس از اجرای موفق GitHub Actions در بخش Actions و قسمت Artifacts قابل دریافت‌اند. این فایل‌ها موقت‌اند و جایگزین نسخهٔ انتشار امضاشده نیستند.

## ساخت

پروژه با Kotlin، Jetpack Compose، Android SDK 36 و JDK 17 ساخته می‌شود. برای ساخت نسخهٔ آزمایشی، از تب Actions گردش‌کار **Build KimiVPN APK** را اجرا کنید.

## حریم خصوصی و امنیت

KimiVPN خودش سرور VPN ارائه نمی‌کند. برای اتصال باید کانفیگ یا اشتراک معتبر از ارائه‌دهنده‌ای که به آن اعتماد دارید وارد کنید. رفتار ثبت گزارش و نگهداری داده‌ها به سرور انتخابی شما نیز وابسته است. هیچ کانفیگ رایگان یا سرور ناشناخته‌ای به‌عنوان امن تضمین نمی‌شود.

## مجوز و رعایت حقوق پروژهٔ پایه

این مخزن از GRoute مشتق شده است. کدهای مشتق‌شده تحت شرایط مجوز **GPL-3.0** پروژهٔ پایه منتشر می‌شوند. متن مجوز و اعلان‌های حق نشر بالادستی باید حفظ شوند. اجزای Xray-core و strongSwan نیز مجوزهای مستقل خود را دارند؛ برای جزئیات به فایل‌های LICENSE و اعلان‌های داخل مخزن مراجعه کنید.

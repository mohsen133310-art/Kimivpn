# pix

### اتصال خصوصی؛ کنترل ساده

**یک کلاینت VPN اندرویدی با Kotlin و Jetpack Compose و موتور sing-box**

رابط تازه با رنگ‌های سفید و بنفش، پشتیبانی فارسی و انگلیسی و ابزارهای مدیریت کانفیگ‌های شخصی.

</div>

## قابلیت‌ها

- پشتیبانی از کانفیگ‌های VLESS، VMess و Trojan
- پشتیبانی از TLS و REALITY
- افزودن کانفیگ از لینک، QR، فایل و اشتراک
- اتصال از طریق سرویس VPN اندروید
- رابط فارسی راست‌چین و انگلیسی
- پوسته‌های روشن، تاریک و AMOLED
- انتخاب سرور و ابزارهای بررسی اتصال

## ساخت پروژه

- Kotlin و Jetpack Compose
- Android SDK 36
- JDK 17
- موتور sing-box libbox نسخهٔ 1.14.4

برای ساخت APK آزمایشی:

```bash
./gradlew :app:assembleDebug
```

نام نمایشی برنامه و پروژهٔ Gradle به Pix تغییر کرده است. شناسهٔ اندرویدی `net.gozar.app` عمداً ثابت مانده تا نصب‌های قبلی بتوانند به‌روزرسانی دریافت کنند.

## وضعیت مهاجرت موتور

هستهٔ sing-box به سرویس VPN اندروید متصل شده است. اتصال واقعی VLESS، VMess، Trojan و REALITY هنوز باید روی دستگاه آزمایش شود. انتقال بعضی امکانات پیشرفته مثل آمار ترافیک و تنظیمات مسیریابی ادامه دارد؛ جزئیات در [گزارش مهاجرت](SINGBOX_MIGRATION.md) آمده است.

## حریم خصوصی و امنیت

Pix خودش سرور VPN ارائه نمی‌کند. فقط کانفیگ‌هایی را وارد کنید که از ارائه‌دهندهٔ آن‌ها اطمینان دارید. سیاست ثبت گزارش و امنیت سرور انتخابی به همان ارائه‌دهنده وابسته است.
